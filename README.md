# 🧠 Deep Learning

A collection of Jupyter Notebooks covering deep learning concepts and implementations using two of the most popular frameworks: **PyTorch** and **TensorFlow**.

---

## 📁 Repository Structure

```
Deep-Learning/
├── Pytorch/         # Deep learning notebooks using PyTorch
└── TensorFlow/      # Deep learning notebooks using TensorFlow
```

---

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Python 3.8+
- Jupyter Notebook or JupyterLab
- PyTorch
- TensorFlow

### 🔥 PyTorch
Notebooks exploring deep learning concepts implemented in PyTorch, including:
- Tensors and autograd
- Building neural networks with `torch.nn`
- Training and evaluation loops
- Convolutional Neural Networks (CNNs)
- And more...

### 🌐 TensorFlow
Notebooks exploring deep learning concepts implemented in TensorFlow/Keras, including:
- Tensors and eager execution
- Building models with the Keras API
- Model training and callbacks
- Convolutional Neural Networks (CNNs)
- And more...
